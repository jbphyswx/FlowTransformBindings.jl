Nonuniform FFTs

plan_nufft plans the transforms between M points x_j in D ≤ 3 dimensions and the Fourier modes k:

\[\text{type 1:}\quad F_k = \sum_j c_j\, e^{\,\iota\, i k\cdot y_j}, \qquad \text{type 2:}\quad c_j = \sum_k F_k\, e^{-\iota\, i k\cdot y_j},\]

with ι = iflag = ±1 (default -1) and y_j = 2π (x_j - origin) / period on each axis. Type 1 is the adjoint of type 2. The mode axes run in CenteredModes or FFTModes order. A plan transforms ntrans fields at a time, and runs on either library through one interface:

FINUFFTBackendFINUFFT (using FINUFFT), cuFINUFFT for CUDA.CuArray nodes (using CUDA)host, CUDAany nthreads; spreading threads over the transforms of a batch
NonuniformFFTsBackendNonuniformFFTs.jl (using NonuniformFFTs)host, any KernelAbstractions device with an FFT1 or Threads.nthreads(); spreading threads over blocks of points
using FlowTransformBindings: FlowTransformBindings as FTB
using NonuniformFFTs: NonuniformFFTs
using Random: Random

Random.seed!(1)
M = 500
x = 2π .* rand(M)
y = 2π .* rand(M)
c = randn(ComplexF64, M)

p = FTB.plan_nufft(FTB.NonuniformFFTsBackend(), ComplexF64, (x, y), (16, 12); tol = 1e-12)
F = FTB.nufft_type1!(FTB.allocate_modes(p), p, c)

kx = FTB.mode_frequencies(p, 1)
ky = FTB.mode_frequencies(p, 2)
direct = [sum(c .* cis.(-(k1 .* x .+ k2 .* y))) for k1 in kx, k2 in ky]
maximum(abs, F .- direct) / maximum(abs, direct)
1.0589535618663539e-12

Real values

A plan for real T stores axis 1 halved, k₁ = 0, …, ⌊n₁/2⌋, and type 2 evaluates the real series in which each row k₁ > 0 also stands for its conjugate at -k, the layout of RFFTAxis. NonuniformFFTs transforms real values natively (has_real_transform); FINUFFT runs them through complex plans on the half.

f = cos.(3 .* x) .* sin.(2 .* y)
pr = FTB.plan_nufft(FTB.NonuniformFFTsBackend(), Float64, (x, y), (16, 12); order = FTB.FFTModes())
Fr = FTB.nufft_type1!(FTB.allocate_modes(pr), pr, f)
size(Fr), FTB.mode_frequencies(pr, 1)
((9, 12, 1), [0, 1, 2, 3, 4, 5, 6, 7, 8])

Library options

A backend tag carries the options of its library alone. FINUFFT and NonuniformFFTs plan their host FFT with FFTW, and take its planner flags as fftw_flags: FFTW.ESTIMATE builds at once, for a plan executed a few times; FFTW.MEASURE times candidate FFTs, a slower build for a faster execution. nothing keeps the library's default. A device plan's FFT takes no FFTW flags.

using FFTW: FFTW

once = FTB.plan_nufft(FTB.NonuniformFFTsBackend(; fftw_flags = FFTW.ESTIMATE), ComplexF64, (x, y), (16, 12))
F1 = FTB.nufft_type1!(FTB.allocate_modes(once), once, c)
FTB.close!(once)
size(F1)
(16, 12, 1)

A plan's lifetime

  • set_nodes! moves a plan to new points, whose count may differ.
  • task_local_plan gives an independent plan over copies of the nodes: one task at a time executes a plan.
  • close! releases the library's resources now and is idempotent. A host plan left unreachable is released at collection; a cuFINUFFT plan's device memory only by close!.

FTB.close!(pr)
FTB.isclosed(p)

FlowTransformBindings.FINUFFTBackend — Type
FINUFFTBackend(; fftw_flags = nothing) <: SpectralBackends.AbstractNUFFTSpectralBackend

Nonuniform FFTs by FINUFFT on host arrays, and by cuFINUFFT on CUDA.CuArray nodes. Requires using FINUFFT (and using CUDA for device nodes). FINUFFT threads its spreading over the transforms of a batch, so a larger ntrans uses more of nthreads. fftw_flags are the FFTW planner flags of a host plan's FFT (FFTW.ESTIMATE, FFTW.MEASURE, …), nothing for FINUFFT's default; a device plan's FFT is cuFFT's and takes none.

FlowTransformBindings.NonuniformFFTsBackend — Type
NonuniformFFTsBackend(; fftw_flags = nothing) <: SpectralBackends.AbstractNUFFTSpectralBackend

Nonuniform FFTs by NonuniformFFTs.jl, on host arrays and on the device of any KernelAbstractions array type with an FFT. Requires using NonuniformFFTs. It threads its spreading over blocks of points, so nthreads is either 1 or Threads.nthreads(), and real values take its real-data transform. fftw_flags are the FFTW planner flags of a host plan's FFT (FFTW.ESTIMATE, FFTW.MEASURE, …), nothing for NonuniformFFTs' default; a device plan's FFT takes none.

FlowTransformBindings.plan_nufft — Function
plan_nufft(backend, T, nodes, nmodes; ntrans = 1, tol = default_tolerance(real(T)),
           order = CenteredModes(), period = 2π, origin = 0, nthreads = 1,
           upsampfac = nothing, iflag = -1) -> AbstractNUFFTPlan{T,D}

A plan for the nonuniform FFTs between the M points nodes = (x₁, …, x_D) and the Fourier modes nmodes = (n₁, …, n_D), ntrans fields at a time:

type 1 (points → modes):  F_k = Σⱼ cⱼ exp(iflag · i k⋅yⱼ)
type 2 (modes → points):  cⱼ = Σ_k F_k exp(-iflag · i k⋅yⱼ)

with iflag = ±1, yⱼ = 2π (xⱼ - origin) / period on each axis (period and origin are numbers or D-tuples), and k over the frequencies of order on each axis. Type 1 is the adjoint of type 2. For real T, axis 1 holds k₁ = 0, …, ⌊n₁/2⌋ ascending and type 2 evaluates cⱼ = Re Σ_k w(k₁) F_k exp(-iflag · i k⋅yⱼ), w(0) = 1, w(k₁ > 0) = 2, so each row k₁ > 0 also stands for its conjugate at -k; type 1 is then the adjoint under the inner product weighted by w. tol is raised to eps(real(T)); nthreads is the library's own thread count. Options of one library, such as its FFT planner flags, are fields of its backend.

FlowTransformBindings.oversampled_spectra — Function
oversampled_spectra(plan) -> (spectra, normfactor, phis)

The oversampled type-1 spectra the plan's last execution computed, one per transform, in FFT order, together with the factors that turn them into the returned modes: the mode at output index I is normfactor / Π_d phis[d][I_d] times the spectrum entry at its frequency. The spectra hold frequencies the returned modes do not, such as +n_d/2 on an even axis. The next execution overwrites them. Defined for a NonuniformFFTs plan of real values in FFTModes order.
