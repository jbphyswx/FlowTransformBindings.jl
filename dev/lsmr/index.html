Least squares

lsmr! minimizes ‖b - A x‖² + damp² ‖x‖² by LSMR (Fong & Saunders, SIAM J. Sci. Comput. 33(5), 2950–2971, 2011) for a stack of right-hand sides sharing one operator: the columns of b along its last axis. The columns iterate together, one application of A and one of A† per iteration serving all of them, and a column that stops leaves the working set. Each stops at the first test of LSMRStatus that holds, and LSMRWorkspace records why, after how many iterations and at what residual.

An operator is any value with the methods below; the solver never forms A.

methodcomputes
lsmr_ncolumns(op)the columns op applies to at once
lsmr_allocate_domain(op), lsmr_allocate_range(op)zeroed stacks of unknowns and data
lsmr_forward!(u, op, v, c, n)u[:, k] = A v[:, k] + c[k] u[:, k], columns 1:n
lsmr_adjoint!(v, op, u, c, n)v[:, k] = A† u[:, k] + c[k] v[:, k]
lsmr_range_norm2!, lsmr_domain_norm2!squared column norms, into a vector on the stacks' device; Euclidean by default

An operator whose range is divided among processes sums the parts in lsmr_range_norm2! and lsmr_adjoint!, and the rest of the recurrence is the same on every process. FunctionOperator builds an operator from two functions, NUFFTOperator takes a NUFFT plan's type 2 with type 1 its adjoint, RightPreconditioned solves through x = N y, and RangeWeighted minimizes Σⱼ wⱼ |bⱼ − (A x)ⱼ|².

using FlowTransformBindings: FlowTransformBindings as FTB
using LinearAlgebra: LinearAlgebra as LA
using Random: Random

Random.seed!(2)
A = randn(40, 10)
b = randn(40, 3)                                 # three right-hand sides
op = FTB.FunctionOperator((y, x) -> LA.mul!(y, A, x), (x, y) -> LA.mul!(x, A', y),
                          zeros(10, 3), zeros(40, 3))
ws = FTB.LSMRWorkspace(op)
X = zeros(10, 3)
info = FTB.lsmr!(X, op, b, ws; maxiter = 100, rtol = 1e-12)
info, ws.status, maximum(abs, X .- A \ b)
((converged = true, iterations = 10, residual = 2.220446049250313e-16), FlowTransformBindings.LSMRStatus[FlowTransformBindings.LSMR_OPTIMAL, FlowTransformBindings.LSMR_OPTIMAL, FlowTransformBindings.LSMR_OPTIMAL], 2.220446049250313e-16)

A Fourier fit to scattered samples: type 2 of a plan evaluates the series at the points, and the fit recovers the coefficients.

using NonuniformFFTs: NonuniformFFTs

x = 2π .* rand(200)
p = FTB.plan_nufft(FTB.NonuniformFFTsBackend(), ComplexF64, (x,), (16,); tol = 1e-12)
F₀ = randn(ComplexF64, 16)
c = FTB.nufft_type2!(FTB.allocate_values(p), p, F₀)

opn = FTB.NUFFTOperator(p)
F = FTB.allocate_modes(p)
fit = FTB.lsmr!(F, opn, c, FTB.LSMRWorkspace(opn); maxiter = 100, rtol = 1e-10)
FTB.close!(p)
fit, maximum(abs, vec(F) .- F₀)
((converged = true, iterations = 14, residual = 5.8186187209976226e-12), 1.3320133860179353e-11)

FlowTransformBindings.lsmr! — Function
lsmr!(X, op, b, ws; maxiter, rtol = √eps, atol = 0, btol = 0, conlim = 1/eps, noise = 0,
      damp = 0) -> (; converged, iterations, residual)

Minimize ‖b - A x‖² + damp² ‖x‖² for each column of b by LSMR, writing each solution into the matching column of X, with A given by op through lsmr_forward! and its companions.

The columns advance together, and a column that stops leaves the working set, so op is applied to the first n columns of each stack it is handed. A column stops at the first test of LSMRStatus that holds (conlim = 0 drops the conlim test). The result says whether every column converged, the most iterations any took and the largest residual; ws holds each column's outcome.

FlowTransformBindings.LSMRWorkspace — Type
LSMRWorkspace(op)

The arrays lsmr! iterates through for op, reusable across solves and across operators of the same shape.

After a solve, the vectors status, iterations, residual (max(‖A†r‖ / ‖A†b‖, eps)), normr, normar, normA (the Frobenius norm of the bidiagonalization, a bound on ‖A‖) and condA (an estimate of cond(A)) hold each column's outcome.

FlowTransformBindings.LSMRStatus — Type
LSMRStatus

Why a column of lsmr! stopped, with r = b - A x ([b; 0] - [A; λI] x under damping):

  • LSMR_RUNNING: it has not.
  • LSMR_ZERO: A†b = 0, so x = 0 solves the problem.
  • LSMR_RESIDUAL: ‖r‖ ≤ btol ‖b‖.
  • LSMR_OPTIMAL: ‖A†r‖ ≤ atol ‖A‖ ‖r‖ or ‖A†r‖ ≤ rtol ‖A†b‖.
  • LSMR_NOISE: ‖r‖ ≤ noise.
  • LSMR_PRECISION: ‖A†r‖ / (‖A‖ ‖r‖) or ‖A†r‖ / ‖A†b‖ fell to eps before a requested tolerance was met.
  • LSMR_CONDITION: the estimate of cond(A) reached conlim or 1/eps.
  • LSMR_MAXITER: the iteration limit.

FlowTransformBindings.NUFFTOperator — Type
NUFFTOperator(plan)

Type 2 of plan, modes to points, as the operator of a least-squares fit by lsmr!, with type 1 its adjoint. The modes of a plan of real values take the inner product under which type 1 is that adjoint, ⟨F, G⟩ = Re Σ_k w(k₁) conj(F_k) G_k with w(0) = 1 and w(k₁ > 0) = 2, so the minimum-norm fit is the one of least energy over the full spectrum the half stands for.

FlowTransformBindings.RangeWeighted — Type
RangeWeighted(op, w)

op with the range inner product ⟨u, u′⟩ = Σⱼ wⱼ conj(uⱼ) u′ⱼ on each column, w nonnegative and shaped like one column of the range: lsmr! then minimizes Σⱼ wⱼ |bⱼ − (A x)ⱼ|², the least squares of a quadrature with weights w, and the adjoint it applies is A^H W. A zero weight removes its point from the fit, whatever b holds there (a masked value, NaN or Inf). The norm and the adjoint go through op's own, on √w ∘ u and w ∘ u, so a range divided among processes sums its parts as before.

Weights that approximate a quadrature of the points, as their Voronoi areas do, bring A^H W A nearer a multiple of the identity than A^H A, and the fit takes fewer iterations. At random points the conditioning is set mostly by the number of points per unknown, which no weighting changes.
